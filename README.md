# Sin-Rollos

> **Sistema de gestión y automatización de trámites internos con flujos de aprobación jerárquicos y trazabilidad total.**

## 🚀 Descripción
**Sin-Rollos** es una plataforma web desarrollada para centralizar y digitalizar la gestión de trámites administrativos (como vacaciones, soporte técnico e insumos). El sistema sustituye los canales informales por un flujo estructurado que garantiza que cada petición llegue al responsable correcto, permitiendo un seguimiento en tiempo real y eliminando cuellos de botella.

## ✨ Características Principales
* **Flujos Jerárquicos:** Aprobación automática basada en la estructura organizacional (Jefes de Área y Administradores).
* **Trazabilidad Total:** Registro histórico (log) de cada interacción para auditorías.
* **Ciclo de Vida Automatizado:** Gestión de estados (Pendiente, En Proceso, Aprobada, Rechazada, Finalizada).
* **Inteligencia de Negocio:** Generación de reportes analíticos y cálculo de tiempos de respuesta.

## 🛠️ Stack Tecnológico
* **Lenguaje:** C# (.NET Core)
* **Base de Datos:** MySQL
* **Arquitectura:** MVC / Modelo C4
* **Metodología:** Agile Unified Process (AUP)
